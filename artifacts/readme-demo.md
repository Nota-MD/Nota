# 写下来的想法，应该保持清晰

Nota 把 Markdown 当作文档树，而不是等待预览的纯文本。输入标记时，排版立即出现在原位；保存到磁盘时，文件仍然是普通、可移植的 Markdown。

## 所见即所得

直接输入 **加粗**、*斜体*、`行内代码`、==高亮== 和 [链接](https://github.com/Nota-MD/Nota)。

- 文档、源码与分屏模式使用同一份内容
- 表格、任务列表和脚注可以原地编辑
- 文件始终保持为标准的 `.md`

> 写作工具应当减少切换，而不是制造新的工作流。

## 一个安静的工作区

Nota 提供标签页、文件树、大纲、自动保存和外部修改检测。界面主题改变应用外壳，文档主题只影响正文。
