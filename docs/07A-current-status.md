## 发布前硬条件

1. `tools/check-version.sh <tag>` 通过。
2. 验证工作流的前端全集、Rust、国际化、文档同步、插件仓库检查和生产构建全绿。
3. 安装包不含插件；策略若变化，同批改 README、`docs/11` 和插件仓库说明。
4. tag 只创建草稿 Release；人工核对产物、构建来源和校验和后再公开。
