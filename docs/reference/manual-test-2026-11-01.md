# Nota 2026-11-01 人工验收单

共 21 项，预计 21–27 分钟；前 9 项是上一轮核心回归，后 12 项对应本轮反馈与手感收口。
每项新建一份文档；保存、关闭、重新打开后再核对源码。

## Linux / WebKitGTK

- [ ] **1. 加粗中的公式**
  1. 输入 `**a$x$b**`。
  2. 点击公式，光标放到源码末尾，按两次 `Right`。
  3. 输入 `Z`。

  通过：保存后为 `**a$x$Zb**`，不是 `**a**$x$Zb`。

- [ ] **2. 中文输入法**
  1. 输入 `**甲$x$乙**`。
  2. 点击公式，源码末尾按 `Right` 退出。
  3. 用 fcitx5/Rime 输入“中文”并确认候选。

  通过：保存后为 `**甲$x$中文乙**`，中文没有进入 `$…$`。

- [ ] **3. 链接中的公式**
  1. 输入 `[$x$](https://example.com)`。
  2. 点击公式，源码末尾按 `Right`，输入 `Z`。

  通过：保存后为 `[$x$Z](https://example.com)`，`Z` 仍在链接中。

- [ ] **4. 键盘连续导航**
  1. 输入 `**$x$**`。
  2. 点击公式，源码末尾按 `Right`，再按 `Home`。
  3. 输入 `Z`。

  通过：保存后为 `**Z$x$**`，光标没有跳进公式，仍可继续输入。

- [ ] **5. 相邻公式与撤销**
  1. 输入 `$a$\(b\)`。
  2. 点击第一个公式，源码末尾按 `Right`，输入 `Z`。
  3. 按一次 `Ctrl+Z`。

  通过：输入后为 `$a$Z\(b\)`；一次撤销只移除 `Z`，两个公式仍完整。

## 本轮反馈追加项

- [ ] **10. GBK / GB2312**

  用 GBK 保存一份中文 `.md`，用 Nota 打开、改一个字、保存。

  通过：中文正常显示；保存后的文件仍是 GBK；状态栏统计悬停显示 `GBK`。

- [ ] **11. 选区字数**

  选中一句话，再点回空光标。

  通过：选中时状态栏显示“已选 N 词”和字符数；点回光标后恢复全文统计。

- [ ] **12. 图片失败与删除**

  打开一张不存在的本地图片；再插入一张正常图片并点击右上角 ×。

  通过：坏图下方有错误告警；正常图片点击 × 后被删除。

- [ ] **13. 代码块光标和字体**

  分别聚焦普通代码块、HTML 代码块和 `math` 围栏。

  通过：光标始终可见；聚焦前后字体、字号、行高不跳变。

- [ ] **14. 列表与引用退出**

  在空列表项按 Enter；在引用中的空行按 Backspace。

  通过：列表项变成普通段落；空行离开引用，已有引用正文保留。

- [ ] **15. Lua 拓展自刷新**

  打开开发者模式，再开启“Lua 拓展自刷新”；修改一个用户插件的 `.lua` 并保存。

  通过：约 1 秒内面板/命令更新。故意写一个语法错误再保存：旧插件继续可用并出现错误通知。关闭开关后再次改文件不应重载。

- [ ] **16. 自动链接**

  输入 `https://example.com`、`www.example.com` 和 `hi@example.com`，分别按空格和 Enter；再粘贴一条网址，并尝试关闭「自动识别链接」。

  通过：开启时三者都成为链接，邮箱使用 `mailto:`；中文逗号留在链接外；关闭后输入与粘贴都保持普通文字。

- [ ] **17. 基础括号配对**

  输入 `(`、`【`、`[` 和 `"`，在空括号中按 Backspace，在括号内侧按 Tab/Shift+Tab，再选中文字输入 `(`；另输入 `don't`。

  通过：自动补闭符、智能引号成对、英文撒号正确、原生闭符不被误吞、空对一次删除、Tab 只移动、选区被包住；关闭「输入时补全括号和引号」后不再自动补。

- [ ] **18. 输入法括号上屏**

  用 fcitx5/Rime 依次上屏 `（`、`你好`、`）`，全程观察候选窗。

  通过：候选期间正文不跳；`（` 上屏后补出 `）`；最后上屏 `）` 时越过已有闭符，源码只为 `（你好）`。

- [ ] **19. 未命名草稿恢复**

  新建未命名文档，输入 `draft-probe`，停手 2 秒；直接结束 Nota 进程后重开，进入「设置 → 文件 → 恢复草稿」。

  通过：出现一份未命名草稿；恢复后内容是 `draft-probe` 且标签为脏；保存前磁盘上没有新文档。

- [ ] **20. 原文件字节稳定**

  准备一份含 CRLF、GitHub 表格、front matter 和行尾空格的 `.md`，记录哈希；用 Nota 打开后不编辑，直接 `Ctrl+S`，再比较哈希。

  通过：哈希不变；存盘不应把 CRLF、表格分隔行或行尾空格规范化。

- [ ] **21. Tab 宽度**

  在「设置 → 编辑器 → 默认缩进」改为 4，在普通段落中按 Tab。

  通过：源码连续出现 4 个空格；改回 2 后新输入的 Tab 恢复为 2 个。
