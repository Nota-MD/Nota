# Nota 2026-11-01 人工验收单

只测 9 项，预计 10–15 分钟。每项新建一份文档；保存、关闭、重新打开后再核对源码。

## Linux / WebKitGTK

- [ ] **1. 加粗中的公式**
  1. 输入 `**a$x$b**`。
  2. 点击公式，光标放到源码末尾，按两次 `Right`。
  3. 输入 `Z`。

  通过：保存后为 `**a$x$Zb**`，不是 `**a**$x$Zb`。

- [ ] **2. 中文输入法**
  1. 输入 `**甲$x$乙**`。
  2. 点击公式，源码末尾按 `Right` 退出。
  3. 用 fcitx5/Rime 输入“中文”并确认候选。

  通过：保存后为 `**甲$x$中文乙**`，中文没有进入 `$…$`。

- [ ] **3. 链接中的公式**
  1. 输入 `[$x$](https://example.com)`。
  2. 点击公式，源码末尾按 `Right`，输入 `Z`。

  通过：保存后为 `[$x$Z](https://example.com)`，`Z` 仍在链接中。

- [ ] **4. 键盘连续导航**
  1. 输入 `**$x$**`。
  2. 点击公式，源码末尾按 `Right`，再按 `Home`。
  3. 输入 `Z`。

  通过：保存后为 `**Z$x$**`，光标没有跳进公式，仍可继续输入。

- [ ] **5. 相邻公式与撤销**
  1. 输入 `$a$\(b\)`。
  2. 点击第一个公式，源码末尾按 `Right`，输入 `Z`。
  3. 按一次 `Ctrl+Z`。

  通过：输入后为 `$a$Z\(b\)`；一次撤销只移除 `Z`，两个公式仍完整。

## Windows / WebView2

- [ ] **6. Windows 重复第 1–3 项**

  中文输入法使用微软拼音。

  通过：结果与 Linux 相同；保存并重开后不丢公式、加粗或链接。

## Linux 与 Windows

- [ ] **7. 加粗中的代码和链接**
  1. 打开 `**a \`code\` b**`。
  2. 打开 `**a [链接](https://example.com) b**`。
  3. 不改内容，保存并重开。

  通过：两份源码逐字不变，代码和链接仍在加粗范围内。

- [ ] **8. 原生打印**
  1. 选浅色文档主题。
  2. 文档包含公式、中文和加粗链接。
  3. 按 `Ctrl+P`：Linux 应进入 GTK 打印，Windows 应进入 WebView2 打印预览。

  通过：公式、中文和链接正常；深色主题会先被拦下。

- [ ] **9. 安装包字体**

  解开本轮 Linux 包和 Windows 包，检查资源目录与 CSS。

  通过：没有独立的 `.ttf`、`.otf`、`.woff`，公式与界面字体仍正常。
