# Nota 0.10.1-beta

这是一个以 Windows 兼容性和更新链路为主的小版本。

## 修复

- 修复 Windows 上帮助窗口与调试日志窗口白屏。
- 修复 Windows 上偏好设置无法打开。
- 修复 Windows 上 LaTeX 与公式无法渲染。
- 帮助、日志和专注警报改用独立 HTML 入口，不再依赖 WebView2 对初始 fragment 的保留行为。
- 设置与 KaTeX 继续按需加载，同时改用相对资源路径并移除不稳定的 modulepreload 包装。

## 更新

- 下载更新时可终止下载，界面会立即进入“正在终止”状态。
- 更新包准备完成后自动关闭旧实例；安装过程等待进程退出，完成覆盖后自动启动新版本。
- Windows NSIS 更新使用 `/S /UPDATE /R`，不再询问是否卸载旧版本，也不再要求用户手动继续。
- Release 资产按 Windows x64、Linux x64、Windows ARM64、Linux ARM64、索引文件的顺序上传，`latest.json` 固定最后。

## 界面

- 缩小右侧拓展栏的“拓展”辅助页签，使其不再抢占插件页签的视觉层级。
- HTML 块在静止状态不显示“HTML”按钮和外框，仅在鼠标悬停或块内获得键盘焦点时显示。
- 点击图片后显示可编辑的 Markdown 图片源文，按回车应用；图片右键菜单增加“复制图片”。
- 右键菜单在未选中文本时隐藏“复制为”，避免显示当前不可用的动作。
- Linux 文件选择器改走 XDG Desktop Portal；GNOME 下使用系统 GTK4 选择器。
- 设置页下拉框改为完全自绘，展开列表、悬停色和选中色均可由界面主题 CSS 控制。
- 格式化工具栏改为居底悬浮胶囊，并按下方状态栏、标签栏的实际高度自动避让。
- 工具栏菜单补齐快捷键、当前项勾选、分组、子菜单和键盘导航。
- “普通文本”重新明确对应 `Ctrl+0`，并显示当前段落状态。
- 收紧代码块上下留白；Adwaita 文档主题下，代码框聚焦后 token 仍使用主题等宽字体。
- 修复深色界面配浅色 Adwaita 文档时 Mermaid 预览被刷成黑底的问题；思维导图恢复白底深字和高对比连线。

## 编辑体验

- 行内 Markdown 标记改为真实行内节点。星号可逐格停留，左右内外边界均可正常输入，不再吸附或闪动。
- 图片源文使用正文样式和可见光标；左键显示源文，右键只打开上下文菜单。
- 粘贴单独图片 URL 时自动插入图片，支持查询串、片段、`text/uri-list` 和常见无后缀图片 CDN。
- 修复表格、HTML 块与图片操作中的焦点、选区同步和复制问题。

## 验证

- 前端：106 组测试、至少 1833 条断言通过。
- Rust：完整单元测试随发布构建执行。
- TypeScript、生产构建、国际化与文档同步检查通过。
- `x86_64-pc-windows-gnu` 目标交叉编译通过且无警告。

Windows 版本的实机覆盖仍然有限，欢迎提交问题和使用反馈。

# English

Nota 0.10.1-beta focuses on Windows compatibility and the update workflow.

- Fixed blank Help and Debug Log windows on Windows.
- Fixed Preferences failing to open and LaTeX failing to render on Windows.
- Help, Debug Log, and Focus Alarm now use dedicated HTML entry points.
- Deferred settings and KaTeX modules now use relative assets without Vite's modulepreload wrapper.
- Update downloads can be canceled.
- Updates close the old process, apply the package after exit, and restart Nota automatically.
- Windows NSIS updates use `/S /UPDATE /R` for silent overwrite and automatic restart.
- Release assets are ordered by platform, with `latest.json` uploaded last.
- The auxiliary Extensions dock tab is more compact.
- HTML blocks hide the “HTML” control and border until hovered or focused.
- Clicking an image exposes its editable Markdown source; Enter applies the change. The image context menu now includes Copy Image.
- “Copy As” is hidden when there is no text selection.
- Linux file dialogs now use the XDG Desktop Portal, including the GTK4 picker on GNOME.
- Settings dropdowns are fully self-drawn and can be themed through CSS.
- The formatting toolbar is now a floating bottom capsule that measures the actual status and tab bars instead of overlapping them.
- Toolbar menus now include shortcuts, current-item checks, grouping, submenus, and keyboard navigation.
- “Normal text” is explicitly mapped to `Ctrl+0` and reflects the current paragraph state.
- Code block vertical spacing is tighter, and Adwaita code tokens stay on the document theme’s monospace stack after focus.
- Fixed Mermaid previews becoming a black surface when a light Adwaita document is paired with a dark UI; mind maps now use light paper, dark text, and visible connectors.
- Inline Markdown delimiters are real document nodes. Every caret boundary around `**text**` accepts input without snapping or flicker.
- Single image URLs pasted as text are inserted as images, including URLs with queries, fragments, `text/uri-list`, and common extensionless image CDNs.
- Image source editing and context-menu image copying now preserve both focus and document selection.
- Frontend: 106 suites and at least 1833 assertions pass.

Windows has had less real-device coverage than Linux. Issue reports and feedback are welcome.
