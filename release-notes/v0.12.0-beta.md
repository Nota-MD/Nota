# Nota 0.12.0-beta

This release expands GitHub Markdown and GitHub Docs compatibility.

## Highlights

- Added insertion commands for all five GitHub alert types: Note, Tip, Important,
  Warning and Caution, each with a type-specific title icon.
- Footnote references and definitions now navigate in both directions.
- Added named-anchor preservation and in-document anchor navigation.
- Added the `<kbd>` inline mark for keyboard keys.
- Added GitHub Docs `{% rowheaders %}` compatibility. Tables retain ordinary GFM
  source and export with real `<th scope="row">` cells.
- Added local display support for common GitHub Octicons, data variables and
  reusable-content Liquid tokens without executing Liquid or changing source.
- Added a non-blocking document check for image alt text, empty links, heading
  jumps and duplicates, footnote pairing, dangerous protocols and unbalanced
  row-header boundaries.
- Upgraded Mermaid from 10.9 to 12.2 and verified both flowchart and mindmap
  rendering in a real Chromium engine.
- Fixed the debug-log viewer by running it in a separate process.
- Standardized document and interface theme directories on `themes/document`
  and `themes/ui`, with one-time migration from older user directories.
- Replaced the Windows portable 7-Zip SFX shell with a non-elevated Nota
  launcher carrying the Nota icon and an `asInvoker` manifest.

## Validation

- TypeScript type checking
- Full frontend test suite
- Rust library tests
- Internationalization and documentation synchronization checks
- Windows GNU cross-build and single-file portable package
