# Nota 0.13.0-beta

This release focuses on editing reliability, theme portability, native printing
and Windows integration.

## 编辑与 Markdown

- Reworked inline Markdown delimiters as real document nodes. Carets can move
  and type at every boundary around bold, italic, highlight, strike, code,
  underline, superscript and subscript text.
- Added explicit Chinese IME composition boundaries. Text committed by the IME
  no longer lands inside an adjacent mark or gets reparsed in the middle of a
  composition.
- Added retroactive delimiter pairing, so an opening delimiter typed before an
  existing closer is promoted without rewriting the surrounding document.
- Fixed tall inline images and other atoms producing a caret that extended
  beyond the normal text line.
- Backspace at the start of a quote removes all quote layers while preserving
  the text.
- GitHub Alerts now follow Typora's editing model: a single semantic left rule,
  a type title, plain `[!TYPE]` source while the title is edited, and no extra
  quote source marker or nested card.
- HTML source blocks use the same compact CodeMirror shell as code, LaTeX and
  Mermaid blocks.
- Remote images used by HTML blocks are cached in memory after first load, so
  navigating to a linked document and back no longer leaves the block blank.
- Added `\[ … \]` and `\( … \)` inline math delimiters and improved block-math
  source/preview layout.

## 主题

- Added ZIP theme import in both Appearance and Document Themes. One package can
  contain interface themes, document themes and relative assets.
- Supports current `ui/`, `ui-styles/`, `document/` and `themes/` layouts,
  wrapper directories, old document dark patches, bundled fonts and licenses.
- Theme identity is derived from `[data-ui-style="…"]`; official packages with
  shared scoped rules now import correctly.
- Replaced the native color input with a self-drawn palette, hexadecimal input
  and full keyboard navigation.
- Updated built-in document styles to use Typora-like quote rules without
  nested gray quote cards.

## 打印与文档

- `Ctrl+P` now opens the platform-native print experience on both Linux and
  Windows. Linux uses the GTK print dialog; Windows uses WebView2/Chromium
  printing.
- The native print dialog follows Nota's selected application language.
- Printing and PDF export continue to require a light document theme.
- HTML and PDF export share the complete document style layer, including code,
  math, Mermaid and HTML preview formatting.

## 拓展与开发者工具

- Added a global Extensions switch. Turning it off stops all extensions and
  hides their menus, panels and settings without deleting installed packages or
  changing per-extension enabled state.
- Added official Knowledge Graph and Vim extensions, plus the updated Writing
  Statistics and Slidev packages.
- Vim provides normal, insert, visual and visual-line modes, motions,
  operators, text objects, registers, macros, search, Ex commands, profiles and
  vimrc-style mappings.
- Developer mode adds an opt-in element inspector showing selectors, computed
  typography, colors, dimensions, spacing and radius.
- Linux debug-log windows now receive GTK/WebView focus correctly, including
  XWayland activation needed by fcitx5 and Rime.

## Windows 与稳定性

- All runtime child processes use Windows `CREATE_NO_WINDOW`. Git, system
  diagnostics, Pandoc, development servers, updater scripts and process-tree
  cleanup no longer flash `cmd` console windows.
- Added a source-level regression check preventing runtime code from bypassing
  the hidden-process launcher.
- Improved the Windows updater and native print integration.
- Reduced startup and memory pressure through deferred CodeMirror, KaTeX,
  Mermaid, language icon and sharing-card modules.

## 发布配套

- Nota Themes 0.7.0 updates the official interface and document theme packages.
- Nota Plugins 0.8.0 publishes all six official extensions from one manifest.
- Release checksums continue to use flat filenames so
  `sha256sum -c SHA256SUMS.txt` works directly in the downloads folder.

## Validation

- Frontend: 125 suites, all exit 0.
- Rust: 710 tests passed.
- TypeScript, production build, internationalization and documentation sync
  checks passed.
- Windows GNU target check passed with zero errors and zero warnings.

# English summary

Nota 0.13.0-beta is a broad editor and ecosystem release. It stabilizes inline
Markdown and IME editing, aligns GitHub Alerts with Typora, adds ZIP theme
import and a self-drawn color picker, moves printing to the native Linux and
Windows dialogs, adds the global extension switch, ships Knowledge Graph and
Vim extensions, and removes Windows console-window flashes from all runtime
child processes.
