# Nota 0.14.2-beta

Nota 0.14.2 is a launch and installation reliability release.

## Linux startup

- The main window is no longer created at an off-screen negative position.
  Wayland compositors may accept the surface and ignore a later global-position
  change, leaving a running process with no visible window.
- The window is created at a normal compositor-managed position. Launching
  Nota again now explicitly calls `show()` before unminimizing and focusing,
  so an existing hidden window can be recovered.

## Windows updates

- Automatic updates no longer invoke NSIS with `/S`.
- After the old Nota instance exits, the update now opens the NSIS installer UI
  with `/UPDATE /R`. The user can see the installer, overwrite the current
  installation and restart Nota.
- This replaces the silent path that could close without installing while the
  visible Nota version remained unchanged.

## Validation

- Startup-window configuration and update-flow tests were updated for the new
  behavior.
- TypeScript, production build, Rust checks and release packaging checks run in
  the same release gate as 0.14.1.

Windows real-device installer interaction remains dependent on this patch's
published package; rebuild/install reports are welcome through GitHub Issues.
