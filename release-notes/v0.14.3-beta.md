# Nota 0.14.3-beta

Nota 0.14.3 fixes the embedded code-block gutter regression seen on WebKitGTK.

## Code-block line numbers

- Document-theme CSS could override CodeMirror's generated scroller display rule.
  WebKitGTK then laid the line-number gutter out as a full-width row above the
  code, making all numbers appear offset from the source.
- Embedded code blocks now explicitly use a horizontal single-row flex layout.
  The gutter is fixed to the left, the code content expands on the right, and
  gutter elements inherit the same line height as `.cm-line`.
- A browser regression compares every line-number top with its corresponding
  source line and verifies that the gutter cannot wrap above the code.

The fix was also verified in an isolated WebKitGTK window using the LaTeX
document theme: numbers 1–20 align with `line01()`–`line20()`.
