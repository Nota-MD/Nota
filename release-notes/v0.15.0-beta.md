# Nota 0.15.0-beta

Nota 0.15.0 focuses on multi-window workflows, document safety and the small
editing details that make long writing sessions predictable.

## Windows, tabs and extensions

- Running windows now have stable numeric IDs. A window can move a tab into
  another Nota window by ID, with optional focus transfer and configurable
  shortcuts.
- Resident windows keep their IDs when tabs open and close, so earlier ID
  addresses remain unambiguous.
- User and extension tabs support pointer-based reordering, including wrapped
  extension tabs. Extension tabs can be closed, restored from a `+` menu, and
  keep their order across dock closes.
- The extension dock has a smooth close transition. Dragging either sidebar past
  its safe minimum shows a red release guide at the window edge and collapses
  only when the pointer is released there.

## Editing and Markdown

- Heading input, bold boundaries, links, inline math, GitHub Alerts, HTML blocks
  and Mermaid rendering received another round of Typora-aligned behavior.
- URL-labelled explicit links now render immediately and serialize to canonical
  Markdown. Link source editing uses the document theme's link color rather than
  the interface accent color.
- Code surfaces honor ligatures; LaTeX suggestions consume vertical arrows
  without leaving the formula editor; empty inline formulas keep a trailing
  backslash before, not after, the closing dollar.
- Mermaid blocks use the available wide editor column while retaining horizontal
  scrolling on narrow windows.
- Wide documents use a centered Typora-style paper column with comfortable side
  margins. The existing text-width setting can narrow the column further.

## Workspace and safety

- Save All and quit-time saving now read each document from its own mirror.
  Same-named files in different directories can no longer overwrite one another.
- Sidebar context menus retain the selected directory: new files and folders are
  created in that folder, and tree view stays in tree view after creation.
- Files and folders can be deleted from the sidebar after explicit confirmation.
  The host validates the workspace boundary and refuses to remove its root.
- Pasted and dropped images now pass through one placement pipeline for HTML
  images, URL lists, blob/data URLs, file URLs and native clipboard images.
  Remote images respect the download/copy settings and are written to disk before
  Markdown is updated.

## Interface

- The first-run guide includes restrained introductions to the editor, notices,
  licensing and extension safety.
- Zoom changes from keyboard, Ctrl+wheel or Preferences show a top-right HUD
  ordered as percentage, minus, plus and reset.
- Native icon assets for Adwaita, Yaru, Breeze, GitHub, Windows and macOS themes
  are shipped through the companion theme release.
- The AI extension now labels the option “Stream output” and accepts OpenAI,
  Responses, Anthropic and Ollama streaming shapes with automatic non-streaming
  fallback.

The companion releases are Nota Plugins `0.9.0-beta` and Nota Themes
`0.8.0-beta`.
