# Nota 0.16.0-beta

Nota 0.16.0 focuses on table interaction, diff readability and settings
consolidation while preserving ordinary GFM Markdown files.

## Spreadsheet table mode

- Added an optional Editor setting for spreadsheet-style table interaction.
- Enable it to show row and column headers, A1 references, an editable cell
  bar, rectangular range selection and a fill handle.
- Fill down and fill right repeat cell contents and can extend the GFM table
  when dragged beyond its current rows or columns.
- Clicking a row or column header selects that row or column.
- The mode is display and editing behavior only. No formulas, workbook metadata
  or private table format is written to the document.
- Empty table cells no longer serialize an automatic `<br />` placeholder.

## Diff readability

- Moved diff rendering into a dedicated component shared by AI, Git and
  external-change views.
- Added stable add/delete/context/hunk/metadata markers and row styling.
- Long lines preserve whitespace and scroll horizontally.
- Long unchanged context runs collapse and can be expanded again.
- Diff regions are focusable, vertically bounded and usable with keyboard
  scrolling.

## Interface

- Status-bar selection counts now show selected over total for the active
  metric, such as `6/26 words`.
- Moved update checks, update notifications, notification position and manual
  software updates into General settings.
- Removed the standalone Update settings page.
- Document-title tests and messages use English test names and ASCII output.
- Blocked browser reload, find-next, downloads, view-source and DevTools
  shortcuts by default. Developer mode now includes an opt-in "Enable WebView
  default shortcuts" switch for restoring native WebView behavior.
- Spreadsheet headers, range outlines and the A1 formula bar now stay below the
  menu bar and toolbar instead of covering application chrome. The front matter
  banner remains above spreadsheet controls while staying below the menu.

## Markdown and editing

- A standalone `[TOC]` line now renders a live, clickable outline while the
  Markdown source remains unchanged.
- Callouts now cover the documented Obsidian types and aliases while retaining
  the existing GitHub alert commands. Unknown types remain ordinary quotations.
- Escaped dollars remain part of inline math, and inline HTML can safely contain
  a literal dollar without starting a new formula.
- Link source editing and rendered links now use the same document-theme color.
  Command-click opens a link directly instead of entering source editing.
- Link source editing also collapses after a click outside the editor. Mixed
  plain-text paste now recognizes every URL and email token without changing
  the visible pasted text.
- Pending heading source stays visible while the caret is anywhere in that
  heading paragraph.
- Resting block math has no frame. Source and preview surfaces appear only in
  edit mode.
- Empty math delimiters no longer prevent a document from opening.

## Rendering

- Mermaid diagrams keep their natural size and only scale down when they exceed
  the content width.
- `gfm` fenced code uses Markdown syntax colors.
- The code-language picker inherits document-theme surfaces, borders, hover
  colors and text colors.
- GTK4 save dialogs accept bare file names when saving a writing-statistics
  image.
- Importing one CSS theme now detects whether it contains UI or document theme
  scopes and routes it to the correct directory. Only that file and its local
  imports, fonts and images are copied, so a large Downloads folder no longer
  causes the import to exceed the theme source limits.
- Spreadsheet overlays continuously track editor scrolling and layout changes,
  preventing stale row headers and formula bars.
- Spreadsheet overlays are clipped to the editor viewport and the A1 formula
  input retains focus when clicked.
- Sequence and flow fences, plus all Mermaid diagram aliases, now use the
  diagram frame and receive missing Mermaid type headers automatically.
  PlantUML and Graphviz source also enters that frame. Oversized diagrams scroll
  inside a bounded preview instead of expanding the whole document.

## AI extension

- Assistant replies render safe Markdown, including headings, emphasis, links,
  lists, tables and fenced code.
- DeepSeek-style providers that stream `reasoning_content` first show a
  thinking state, then replace it with the final answer as content arrives.
- Mixed plain-text paste linkifies all recognized URL and email tokens.
- AI extension 0.1.3 supports importing one or many personas from JSON,
  Markdown or plain text. AI extension 0.1.6 adds an always-available custom
  preset editor, concise English system instructions and explicit stale-document
  handling.
- AI streaming now sends the required POST request. DeepSeek-style streams are
  displayed incrementally instead of failing with HTTP 405 and silently falling
  back to a complete response.
- Extension API versions now use `vMAJOR.MINOR`; host API `v2.3` accepts
  compatible older minors and rejects newer or foreign major versions.
- Incompatible directories remain listed with a red error and produce one
  aggregate startup notification. Importing an incompatible package opens a
  blocking rejection dialog and writes nothing.
- Rejection guidance distinguishes a plugin that needs a newer host from a
  plugin whose legacy major API requires its developer to update it.

- Translated maintainer guidance, contribution rules, release notes and the

- Added language-audit enforcement against newly introduced Chinese production

- Made entry configuration, platform manifests and the i18n wrapper ASCII.
