# Nota 0.17.0-beta

Nota 0.17.0 focuses on extension-owned spreadsheet formulas, nested Vim input,
LaTeX table layering and smaller release binaries. Files remain ordinary GFM
Markdown.

## Spreadsheet formulas

- Added extension API `v2.4` table snapshots, temporary rendered values,
  undoable table writes, setting locks and localized table actions.
- Added the `nota.sheet-formulas` extension with Excel-compatible references,
  arithmetic, logical, text and lookup functions.
- Formula results are display-only until **Keep Values** is selected from the
  table context menu.
- Formula cells follow the selected cell, and the A1 formula input preserves
  normal caret placement and text selection.
- Cycles return `#CYCLE!` instead of recursing indefinitely.
- Markdown highlight syntax such as `==notice==`, escaped equals and inline
  code do not start formulas.
- Installing the extension enables spreadsheet table mode and locks its setting
  while the extension is active.

## Editing and rendering

- Vim input now applies inside fenced code, Mermaid and block LaTeX source
  editors while preserving each editor's selection and undo state.
- Inline LaTeX suggestions inside tables stay above the table controls and are
  no longer clipped by cells, previews or the editor viewport.
- The first `/` or `\` in empty inline math keeps a visible source slot and a
  stable caret in WebKitGTK.
- Mermaid previews fit the available width and height before using scrolling,
  preventing tall flowcharts and mind maps from showing only their upper half.
- The formula bar remains mounted while pointer focus temporarily leaves the
  table.

## Desktop and packaging

- Preferences first try an in-process window and fall back to a dedicated
  process and top-level window, matching the reliable debug-log lifecycle.
- Release builds use size-oriented code generation, fat LTO and abort unwinding.
- Production source, identifiers and comments complete the English-only
  migration. User-facing Chinese remains available through localization files.

## Validation

- Version consistency, TypeScript type checking, the production frontend build
  and the WOFF2 asset check pass.
- Frontend unit tests, Rust library tests, localization checks, source-language
  audits and documentation synchronization pass.
- The official extension contract validates host API `v2.4` and the new
  spreadsheet formula package.

## Manual review

0.17.0-beta remains a beta release. Table formulas, spreadsheet interaction,
table and LaTeX layering, source and code appearance, diff rendering, nested
Vim input, settings presentation, sidebars and tabs, themes, IME boundaries,
printing and platform lifecycle still require real-window verification. The
current review matrix is in
[`docs/07A-current-status.md`](../docs/07A-current-status.md#manual-visual-review-gaps-for-0170-beta).

The previous release is Nota 0.16.0-beta.
