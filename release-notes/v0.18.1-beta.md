# Nota 0.18.1-beta

Nota 0.18.1-beta adds safe settings-package restoration and makes official and
organization distributions instances of the same Distribution Profile system.
Files remain ordinary GFM Markdown.

## Settings packages

- Added a preflight viewer for `.nota-backup` and ZIP settings packages.
- Added selective import for program settings, themes, dictionaries, extension
  state, extension settings and extension data.
- Added path allowlists, archive size limits, symlink rejection and manifest
  validation.
- Import is transactional and creates a timestamped backup before replacing
  existing data.
- Sensitive categories remain unselected by default.

## Distribution Profiles

- Added the explicit `official` profile under `distributions/`.
- Added `npm run build:dist -- <profile>` and the `build:org` compatibility alias.
- Profiles now define application identity, icons, data directories, defaults,
  updates, legal resources, first-run onboarding and optional bundled extensions.
- Added static localized HTML onboarding with build-time and runtime sanitization.
- Added distribution-specific legal notices and update channels.
- Added organization bootstrap backups and validation.
- Added independent single-instance and window-registry paths for organization
  distributions.
- Added `npm run build:org -- example-university --dry-run` validation.

## Extensions

- Extension programs remain exportable as `.nota-plugin`.
- Extension settings and data remain separate from extension code and are
  exported through `.nota-backup`.
- Bundled organization extensions use the normal package validation and
  capability model.

## Editor and editor shell fixes

- Bare domains such as `github.com` are qualified before being passed to the
  system opener.
- The command palette input spans the full panel width in WebKit.
- The DevKit editor input playback path is included from the preceding source
  commit.

## Validation

- `npm run verify:light` passes.
- The full Rust library suite passes: 759 tests.
- TypeScript type checking, frontend smoke tests, localization checks, source
  audits and documentation synchronization pass.
- Official and organization Distribution Profile dry runs pass.

The previous release is Nota 0.18.0-beta.
