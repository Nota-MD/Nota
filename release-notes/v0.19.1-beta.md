# Nota 0.19.1-beta

Nota 0.19.1-beta is a settings, startup and interface stability release.
Documents remain ordinary GFM Markdown.

## Settings and distribution profiles

- Main, Settings and About windows now send focused settings patches instead of
  writing stale full snapshots.
- Settings files are flushed and atomically replaced, including a write-through
  Windows path.
- Completing onboarding updates only `general.onboarding_seen`.
- Embedded Distribution Profile bootstrap settings run once on first launch and
  never replace preferences on later launches or upgrades.

## Startup and editor

- Fixed a StrictMode cleanup race that could leave the editor mount empty on
  startup.
- Inline LaTeX previews no longer wrap formulas into a tall, narrow column.
- Focus mode dims non-caret content only while focus mode is active.
- The debug-log utility window no longer reads main application state that it
  intentionally does not create.
- Linux utility windows launch from the running executable, so a development
  rebuild cannot leave About, Settings or the debug log pointing at a deleted
  binary path.
- Linux AppImages isolate bundled GIO modules and normalize the input module
  when their GTK runtime uses X11, avoiding startup crashes on newer Debian and
  Fedora hosts.

## Interface

- Sidebar and dock panel opening now uses compositor-friendly transforms instead
  of per-frame width and layout animation.
- The editor reserves panel space once, while both panels slide independently
  and retain their resize behavior.

## Validation

- TypeScript, frontend tests, production build, localization, documentation
  synchronization, Rust tests and both Chromium and WebKitGTK browser suites
  are required release gates.

Nota 0.19.1-beta remains a beta release. The previous release is Nota
0.19.0-beta.
