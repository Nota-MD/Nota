# Nota 0.19.2-beta

Nota 0.19.2-beta is a focused formula typography fix.

## Formula previews

- Inline and block formulas now use KaTeX's canonical font metrics before any
  document-theme font fallback.
- Formula surfaces reset inherited letter spacing, word spacing, ligatures and
  line height.
- Commands such as `\sum_{1}^{2}\LaTeX` retain their intended compact layout
  even when the active document theme uses a monospaced math fallback or
  aggressive typography rules.
- Floating inline previews are covered by the same isolation as formulas inside
  the editor.

## Images and source mode

- HTML images keep their explicit width and height when converted into the
  editor image model, including later Markdown serialization.
- The Nota SVG declares a numeric intrinsic size so WebKitGTK does not render it
  as a zero-sized data-URL image.
- Empty source mode shows only the Markdown placeholder; its active-line
  background is suppressed while the document is empty.

## Validation

- Math NodeView tests pass.
- The exact reported formula passes in Chromium.
- WebKitGTK browser E2E passes.
- Focused Chromium E2E covers formula padding, image dimensions and the empty
  source-mode state.
- TypeScript and the production frontend build pass.

Nota 0.19.2-beta remains a beta release. The previous release is Nota
0.19.1-beta.
