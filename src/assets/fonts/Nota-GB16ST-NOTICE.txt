Nota GB16ST Bitmap
==================

This font is a modified format conversion of WenQuanYi Bitmap Song 16px
bitmap glyphs. The original project is:

  WenQuanYi Bitmap Song 1.0 RC1
  Copyright (C) 2004-2010, WenQuanYi Project Board of Trustees and
  Qianqian Fang
  https://sourceforge.net/projects/wqy/files/wqy-bitmapfont/
  http://wenq.org/

Modifications for Nota:

  - extracted the 16x16 monochrome bitmap glyphs;
  - repackaged them as EBDT/EBLC bitmap strikes inside an OpenType font;
  - created regular and bold font faces used by the CDE interface theme.

The modified files are:

  NotaGB16ST-EBDT-Regular.ttf
  NotaGB16ST-EBDT-Bold.ttf
